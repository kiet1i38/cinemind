How to read this flow

Each focused view follows one authored path. The canvas intentionally shows only the selected step and its nearest neighbors, so the request boundary stays readable.

  • Use the view tabs to switch between catalog reads, signal writes, login promotion and reset scope.
  • Use the step list or arrows to move through the complete story; the diagram updates to a small window around that step.
  • Click a node to see its real repository path and the database record it reads or writes.
  • Use Copy link after selecting a view, step or node to share the same moment.
